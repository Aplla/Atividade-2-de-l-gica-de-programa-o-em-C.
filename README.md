# Atividade 2 de lógica de programação em C

Projeto desenvolvido durante meus estudos iniciais de lógica de programação utilizando a linguagem C.

## Objetivo

O foco dessa atividade foi praticar conceitos fundamentais da linguagem, como:

* Variáveis
* Entrada e saída de dados
* Estruturas condicionais
* `switch case`
* Estruturas de repetição
* Lógica de programação
* Interação com usuário no terminal

## Sobre o projeto

O programa simula um pequeno sistema de autoatendimento de hotel, permitindo que o usuário:

* informe o número do quarto
* faça avaliações de serviços
* solicite serviço de quarto
* realize pedidos no restaurante
* confirme pedidos
* valide entradas do usuário

Durante o desenvolvimento também comecei a praticar o uso de `while` para tratamento de entradas inválidas.

## Observações

Este projeto foi feito enquanto eu ainda estava aprendendo os conceitos básicos da linguagem C, então algumas partes do código podem não estar totalmente otimizadas.

Mesmo assim, decidi manter o projeto no GitHub para registrar minha evolução como programador e acompanhar meu progresso ao longo dos estudos.
